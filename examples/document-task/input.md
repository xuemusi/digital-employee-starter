# 原创虚构输入：社区书店开业通知

本文件所有名称、地点、活动与安排均为原创虚构，仅用于教学。不存在真实店铺、真实开业活动或对外承诺；不得据此发布真实通知。

## 任务

为社区居民写一份新店开业通知，适合张贴在社区公告栏。用简体中文，语气友好、清楚，不过度营销。

## 允许使用的全部事实

- 店名：示例书店。
- 事项：新店开业，欢迎社区居民到店阅读。
- 时间：周六 10:00—18:00。虚构场景不绑定具体日历日期，不补充年月日。
- 地点：示例路10号。
- 活动范围：仅店内阅读，不提供外借。
- 赠品：免费书签，共100枚，送完即止；每人可领1枚。
- 不售课，不收集联系方式，无需提供手机号码或扫码登记。
- 未提供任何折扣、满减或其他优惠；不要捏造优惠、课程、抽奖或购买条件。

## 交付要求

- 正文包含一个标题和清楚的活动信息，正文约150—250个中文字符（含标点，不计标题）。
- 标题或正文开头明确标注“虚构教学示例”，避免被误当真实通知。
- 必须覆盖店名、周六时段、地点、店内阅读限制、书签数量及领取规则、不售课和不收集联系方式。
- 不添加老板身份、经营历史、读者评价、联系方式、价格、销量、奖项或保证。
- 不替活动添加报名、转发、购买或关注账号的要求。
- 本文件是需求输入，不等于本轮用户已确认。仍需主会话按战队协议取得确认，再安排写稿。
